## ✨ What it is

**Sản Xuất Phim** turns written prompts into finished **images and videos** for animation, ads, social clips and short films. You describe a scene once and the app runs it through the generator you choose, downloads the result, and keeps your characters and settings consistent from shot to shot.

It is a **desktop app for Windows** (with preview builds for macOS and Linux), driving the AI tools in your own logged‑in browser profiles — your accounts, your subscriptions — in one production queue.

## 🔌 Supported providers

| Provider | Images | Video |
|---|:---:|:---:|
| **Google Flow (Veo)** | ✅ | ✅ |
| **Google Vids** | — | ✅ |
| **ChatGPT (GPT Image)** | ✅ | — |
| **Grok (Imagine)** | ✅ | ✅ |

You use the plans you already pay for. The app signs in through separate Chrome profiles so you can run several accounts side by side.

## ⬇️ Download

Grab the build for your system from the **[Releases page](https://github.com/WABYDEV/sanxuatphim.com/releases/latest)**:

| Platform | File | How to run |
|---|---|---|
| **Windows** 64-bit (x64) | `SanXuatPhim-<version>-Windows-64bit.exe` | Download and run |
| **Windows** ARM64 | `SanXuatPhim-<version>-Windows-ARM64.exe` | Download and run |
| **Linux** 64-bit | `SanXuatPhim-<version>-Linux-64bit` | `chmod +x`, then run |
| **macOS** (universal) | `SanXuatPhim-<version>-macOS.zip` | Unzip to get the `.app` |

Each release ships a **`checksums.json`** (name · size · SHA‑256 of every file) so you can verify integrity, and so the app can update itself.

> **Windows is the full‑featured platform.** macOS and Linux builds are for trying the interface — some browser‑automation features are still being finished there.

## 🧩 Features

- **Prompt → image & video** across Google Flow (Veo), Google Vids, ChatGPT and Grok.
- **Reference images by `@tag`** — a character or prop folder; type `@daniel` and its picture rides along with the shot.
- **Character & prop library** reused consistently across every scene.
- **Multi‑job queue** that keeps running as you type, with several browser profiles in parallel.
- **Video stitching** and scene‑chaining (the last frame of one clip becomes the first of the next).
- **Automatic Gemini watermark removal** on generated video.
- **Self‑updating** — the app checks for new versions and installs them in place.

## 🖥 Requirements

- **Windows 10 or 11** (recommended) for the full feature set.
- **Google Chrome** installed.
- An internet connection.

## 🔑 Activation & licensing

The app is activated **per machine** with a licence key. Open **Settings › Licence** in the app and paste your key.

Buy a key or start a trial at **[sanxuatphim.com](https://sanxuatphim.com)**.

## 🔁 Updates

The app reads `checksums.json` from the latest release and updates itself in place on **Windows and Linux** (macOS updates are downloaded manually).
