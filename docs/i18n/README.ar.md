## ✨ ما هو

يحوّل **Sản Xuất Phim** مطالبات النص إلى **صور ومقاطع فيديو** جاهزة للرسوم المتحركة والإعلانات ومقاطع التواصل الاجتماعي والأفلام القصيرة. تصف المشهد مرة واحدة، فيشغّله التطبيق عبر المولّد الذي تختاره، وينزّل النتيجة، ويبقي شخصياتك وإعداداتك متسقة من لقطة إلى أخرى.

هو **تطبيق سطح مكتب لنظام Windows** (مع إصدارات تجريبية لـ macOS وLinux) يشغّل أدوات الذكاء الاصطناعي داخل ملفات تعريف المتصفح الخاصة بك والمسجّل دخولها — حساباتك واشتراكاتك — في قائمة إنتاج واحدة.
