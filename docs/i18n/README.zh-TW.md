## ✨ 簡介

**Sản Xuất Phim** 把文字提示詞變成可用於動畫、廣告、社群短片與短片的**影像與影片**。你只需描述一次場景，應用程式便透過你選擇的生成器執行它、下載結果，並在鏡頭之間保持角色與設定一致。

這是一款 **Windows 桌面應用程式**（另有 macOS 與 Linux 預覽版），在你自己已登入的瀏覽器設定檔中驅動 AI 工具 —— 你的帳號、你的訂閱 —— 並歸入一條生產佇列。

## 🔌 支援的提供者

| 提供者 | 影像 | 影片 |
|---|:---:|:---:|
| **Google Flow (Veo)** | ✅ | ✅ |
| **Google Vids** | — | ✅ |
| **ChatGPT (GPT Image)** | ✅ | — |
| **Grok (Imagine)** | ✅ | ✅ |

你使用的是自己已付費的方案。應用程式透過獨立的 Chrome 設定檔登入，可並行執行多個帳號。

每個版本都附帶 **`checksums.json`**（每個檔案的名稱 · 大小 · SHA‑256），用於校驗完整性並供應用程式自動更新。

> **Windows 是功能完整的平台。** macOS 與 Linux 版本用於試用介面 —— 部分瀏覽器自動化功能仍在完善中。

## 🧩 功能

- **提示詞 → 影像與影片**，涵蓋 Google Flow (Veo)、Google Vids、ChatGPT 和 Grok。
- **以 `@tag` 引用參考圖** —— 角色或道具資料夾；輸入 `@daniel`，其圖片即隨鏡頭帶入。
- **角色與道具庫**，在每個場景中一致重複使用。
- **多工作佇列**，邊輸入邊執行，多個瀏覽器設定檔並行。
- **影片拼接**與場景銜接（上一段的末格成為下一段的首格）。
- **自動移除 Gemini 浮水印**。
- **自動更新** —— 應用程式檢查新版本並就地安裝。

## 🖥 系統需求

- **Windows 10 或 11**（建議），以取得完整功能。
- 已安裝 **Google Chrome**。
- 可用的網路連線。
