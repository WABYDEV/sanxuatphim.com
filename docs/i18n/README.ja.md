## ✨ 概要

**Sản Xuất Phim** は、テキストのプロンプトをアニメーション・広告・SNS クリップ・短編向けの完成した**画像と動画**に変えます。シーンを一度記述すれば、選んだジェネレーターで実行し、結果をダウンロードし、カットごとにキャラクターや設定を一貫させます。

これは **Windows 向けデスクトップアプリ**（macOS と Linux のプレビュー版あり）で、自分がログイン済みのブラウザープロファイル内の AI ツールを—あなたのアカウント、あなたのサブスク—1 つの制作キューで動かします。

## 🔌 対応プロバイダー

| プロバイダー | 画像 | 動画 |
|---|:---:|:---:|
| **Google Flow (Veo)** | ✅ | ✅ |
| **Google Vids** | — | ✅ |
| **ChatGPT (GPT Image)** | ✅ | — |
| **Grok (Imagine)** | ✅ | ✅ |

すでに支払っているプランを使います。アプリは個別の Chrome プロファイルでログインするため、複数アカウントを並行して使えます。

## ⬇️ ダウンロード

**[all.zip · S3](https://s3.upgo.io/sanxuatphim/releases/latest/all.zip)** からお使いのシステム向けのビルドを入手してください：

| プラットフォーム | ファイル | 実行方法 |
|---|---|---|
| **Windows** 64-bit (x64) | [`SanXuatPhim-Windows-64bit.exe`](https://s3.upgo.io/sanxuatphim/releases/latest/SanXuatPhim-Windows-64bit.exe) | ダウンロードして実行 |
| **Windows** ARM64 | [`SanXuatPhim-Windows-ARM64.exe`](https://s3.upgo.io/sanxuatphim/releases/latest/SanXuatPhim-Windows-ARM64.exe) | ダウンロードして実行 |
| **Linux** 64-bit | [`SanXuatPhim-Linux-64bit`](https://s3.upgo.io/sanxuatphim/releases/latest/SanXuatPhim-Linux-64bit) | `chmod +x` して実行 |
| **macOS** (universal) | [`SanXuatPhim-macOS.zip`](https://s3.upgo.io/sanxuatphim/releases/latest/SanXuatPhim-macOS.zip) | 解凍して `.app` を取得 |

各リリースには **`checksums.json`**（各ファイルの名前・サイズ・SHA‑256）が付属し、整合性の検証とアプリの自動更新に使われます。

> **Windows がフル機能のプラットフォームです。** macOS と Linux のビルドは UI を試すためのもので、一部のブラウザー自動化機能はまだ仕上げ中です。

## 🧩 機能

- **プロンプト → 画像と動画**（Google Flow (Veo)、Google Vids、ChatGPT、Grok）。
- **`@tag` による参照画像** — キャラクターや小道具のフォルダー。`@daniel` と入力すると、その画像がカットに付いていきます。
- **キャラクター・小道具ライブラリ** をすべてのシーンで一貫して再利用。
- **複数ジョブのキュー** が入力中も動き続け、複数のブラウザープロファイルを並行実行。
- **動画の連結** とシーンチェーン（あるクリップの最終フレームが次の先頭フレームに）。
- **生成動画の Gemini 透かしを自動除去**。
- **自動更新** — 新しいバージョンを確認してその場でインストール。

## 🖥 動作環境

- フル機能には **Windows 10 または 11**（推奨）。
- **Google Chrome** がインストール済み。
- インターネット接続。

## 🔑 アクティベーションとライセンス

アプリは**マシンごと**にライセンスキーでアクティベートします。アプリ内の **設定 › ライセンス** を開き、キーを貼り付けてください。

キーの購入や試用は **[sanxuatphim.com](https://sanxuatphim.com)** で。

## 🔁 更新

アプリは最新リリースの `checksums.json` を読み、**Windows と Linux** ではその場で自動更新します（macOS は手動ダウンロード）。
