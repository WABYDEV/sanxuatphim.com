## ✨ 소개

**Sản Xuất Phim**은 텍스트 프롬프트를 애니메이션, 광고, 소셜 클립, 단편용 완성된 **이미지와 영상**으로 바꿉니다. 장면을 한 번 기술하면 선택한 생성기로 실행하고 결과를 내려받으며, 샷마다 캐릭터와 설정을 일관되게 유지합니다.

**Windows용 데스크톱 앱**(macOS·Linux 미리보기 빌드 포함)으로, 로그인된 자신의 브라우저 프로필 안에서 AI 도구를 — 당신의 계정, 당신의 구독 — 하나의 제작 대기열로 구동합니다.

## ⬇️ 다운로드

**[Releases 페이지](https://github.com/WABYDEV/sanxuatphim.com/releases/latest)** 에서 사용 중인 시스템용 빌드를 받으세요:

| 플랫폼 | 파일 | 실행 방법 |
|---|---|---|
| **Windows** 64-bit (x64) | `SanXuatPhim-<버전>-Windows-64bit.exe` | 다운로드 후 실행 |
| **Windows** ARM64 | `SanXuatPhim-<버전>-Windows-ARM64.exe` | 다운로드 후 실행 |
| **Linux** 64-bit | `SanXuatPhim-<버전>-Linux-64bit` | `chmod +x` 후 실행 |
| **macOS** (universal) | `SanXuatPhim-<버전>-macOS.zip` | 압축을 풀어 `.app` 얻기 |

각 릴리스에는 **`checksums.json`**(각 파일의 이름 · 크기 · SHA‑256)이 포함되어 무결성 검증과 앱 자동 업데이트에 사용됩니다.

> **Windows가 전체 기능 플랫폼입니다.** macOS·Linux 빌드는 인터페이스를 체험하기 위한 것으로, 일부 브라우저 자동화 기능은 아직 마무리 중입니다.

## 🧩 기능

- **프롬프트 → 이미지와 영상** (Google Flow (Veo), Google Vids, ChatGPT, Grok).
- **`@tag`로 참조 이미지** — 캐릭터나 소품 폴더. `@daniel`을 입력하면 해당 이미지가 샷에 함께 들어갑니다.
- **캐릭터·소품 라이브러리** 를 모든 장면에서 일관되게 재사용.
- **다중 작업 대기열** 이 입력 중에도 계속 실행되며, 여러 브라우저 프로필을 병렬로.
- **영상 이어붙이기** 와 장면 연결(한 클립의 마지막 프레임이 다음 클립의 첫 프레임).
- **생성 영상의 Gemini 워터마크 자동 제거**.
- **자동 업데이트** — 앱이 새 버전을 확인해 제자리에 설치합니다.
